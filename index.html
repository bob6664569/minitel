Tokens

Eight colours in the Videotex attribute order. On a monochrome Minitel they become grey levels: the whole kit re-skins itself. Try it on this page.

  • blackESC 4/0 5/00 %
  • blueESC 4/4 5/440 %
  • redESC 4/1 5/150 %
  • magentaESC 4/5 5/560 %
  • greenESC 4/2 5/270 %
  • cyanESC 4/6 5/680 %
  • yellowESC 4/3 5/390 %
  • whiteESC 4/7 5/7100 %

Everything snaps to the character cell: --mt-col × --mt-row, one 8×10 glyph. Mosaic strokes are a half cell wide and a third of a row tall.

Terminal

A Videotex decoder that follows the STUM1B: serial attributes, G0/G1/G2 sets, repetition, row 0, CSI and PRO sequences. It draws at the Minitel's native 320×250 and a WebGL shader does the tube.

// A page, built with the writer
import { Page }
  from './src/js/index.js';

const page = new Page()
  .clear()
  .header({ title: 'Météo',
            code: 'METEO' })
  .menu(["Aujourd'hui", 'Demain',
         'Carte de France'])
  .bigText(16, 24, '19°',
           { color: 'green' })
  .prompt();

page.bytes();  // for a real Minitel
terminal.write(page); // 1200 bd

Services

Write a Télétel service as an async function. The session echoes what users type, handles fields and function keys, and the same code can drive a real Minitel over Web Serial.

export default {
  code: 'HELLO',
  async run(session) {
    session.write(new Page().clear()
      .header({ title: 'Bonjour' })
      .print(10, 3, 'Nom :'));

    const { key, value } =
      await session.input({
        row: 10, col: 9, length: 20,
      });

    if (key === 'ENVOI') {
      session.write(new Page()
        .print(14, 3, `Salut ${value}`,
          { size: 'double' }));
    }
  },
};

Get started

No build step. One stylesheet, one optional module.

<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/bob6664569/minitel@master/src/css/minitel.css">

<!-- Custom elements: terminal, device, keyboard, mosaics -->
<script type="module" src="https://cdn.jsdelivr.net/gh/bob6664569/minitel@master/src/js/elements/index.js"></script>

<body class="mt" data-mt-theme="color">
  <header class="mt-header">
    <span class="mt-header__code">3615 HELLO</span>
    <h1 class="mt-header__title">Bonjour</h1>
  </header>
  <mt-minitel></mt-minitel>
</body>
